# 馒头 Bunbun · 用户手册

> 一只住在你桌面上的毛玻璃小馒头。它会看着你的鼠标、跟你聊天、盯你干活、听你放的歌点头、陪你自习、到深夜自己去睡觉。零素材、纯代码画出来的，也可以换上你自己的角色皮肤。

本手册面向普通用户，按「你能拿它做什么」来组织。带 AI 的功能需要你自己填一个大模型 API Key（见 [第 4 节](#4-和它聊天)），不填也能用绝大部分陪伴功能。

## 1. 快速开始

启动后，馒头会从桌面上「浮现」出来，说一句问候，然后开始待机——它是一个白色半透明的圆馒头，只有两只大眼睛，眼珠会一直追着你的鼠标转。

- **它浮在所有窗口最上层**，铺满整个屏幕的透明层，但**只有碰到它本体时才挡鼠标**，其余地方的点击都会正常穿透到桌面和其他程序。
- 想打开菜单：**把鼠标移到馒头身上**，它周围会浮现几个圆按钮（聊天、待办、锐评屏幕、设置等）。
- 想让它挪窝：**直接拖动它**，可以拖到屏幕任意角落，甚至拖到另一块显示器上。
- 想调设置或退出：悬停 → **齿轮按钮**（设置）→ 最底部有「退出桌宠」。

第一次使用建议先去 **设置 → API 配置** 填一个大模型 Key，聊天、拆解待办、屏幕锐评这些「聪明」功能才会亮起来。只想要个安静的桌面伙伴的话，跳过也完全可以。

## 2. 和它相处：基础交互

### 悬停菜单
鼠标移到馒头身上，几个圆按钮浮现：

| 按钮 | 作用 |
|---|---|
| 💬 聊天 | 打开对话气泡输入框 |
| 📋 待办·报告 | 待办清单、研究进展、观察记录、工作报告 |
| 👁 锐评屏幕 | 让它截图点评你正在干什么 |
| 🔷 打开扣子 | 只在你电脑上开着「扣子」客户端时出现，一键把扣子窗口拉到前台 |
| ⚙ 设置 | 所有配置项 + 退出 |

### 拖动 & 多屏跳岛
按住馒头拖动即可移动。拖动时它会顺着甩动方向轻轻倾斜，松手回弹。**拖到屏幕边缘时，窗口会「跳」到你光标所在的那块显示器**，多屏用户可以把它带去任意一块屏。

### 眼睛（永远在线）
- **视线追随**：眼珠随全屏鼠标移动。
- **随机眨眼**：每隔几秒眨一次，偶尔是俏皮的单眼 wink。
- **眼型随心情变**：睡觉慢慢闭上、惊讶瞪大、无语一眼扁一眼圆、难过垂眼……

### 戳一戳
直接点馒头，它会原地一惊、眼睛瞪大。**8 秒内连戳 5 次**，它会满头黑线 + 被冰封住，甩你一句「……够了。」（之后冷却 1 分钟）。戳它时还有三成概率它会主动开口回应你（需要 AI）。

## 3. 表情与心情

馒头有 **7 种情绪表情**，会配合眼型、粒子和专属音效：

| 情绪 | 表现 |
|---|---|
| 愉悦 happy | 眉眼弯弯，冒 ✦ 火花 |
| 惊讶 surprise | 瞪大眼 |
| 生气 angry | 横条眼 + 发抖 |
| 难过 sad | 垂眼 + 掉泪滴 |
| 无语 speechless | 一眼扁 + 大颗汗滴 |
| 低气压 gloomy | 眼睛微放大 + 自发光变强 |
| 黑线 blackline | 双眼缩成细线 + 满头黑线 |

**什么时候会切表情？**
- 聊天时 AI 会根据语气自动切（比如它说到开心的事就笑）。
- 完成一项待办 → 愉悦；跳过 → 无语。
- 屏幕监督判定你认真 → 愉悦夸你；判定摸鱼 → 生气。
- 各种本地台词也会带对应表情。

不聊天、不干活时，它就回到平常的待机脸。

## 4. 和它聊天

### 怎么聊
悬停 → 💬 → 在输入框打字，Enter 或点发送。回复会以**流式打字机气泡**逐字冒出来，带轻微的电子音，长回复自动分成几个气泡换气。

- **🕐 历史**：切到会话列表，点开任意旧对话继续，或删除（二次确认）。最多保留 100 个会话。
- **➕ 新对话**：另起一段干净的对话。
- **人设**：在 设置 → 基础 → 人设文本 里可以改它的身份和性格（默认是「清冷淡漠」的调调），里面写 `{petName}` 会自动替换成你给它起的名字。**名字和人设是跟着形象走的**——小馒头和每个角色包各记一套，切换形象自动换用各自的设定，互不污染；配置后台形象卡上的「人设」按钮和设置面板改的是同一份，两边同步。

### 配置 API（聊天/拆解/锐评的前提）
设置 → API 配置，支持 **12 家服务商**，选好后填 Base URL / 模型 ID / Key，点「测试连通」验证：

> 智谱 GLM、DeepSeek、豆包（火山）、Kimi、Kimi For Coding、通义千问、硅基流动、OpenAI、Anthropic、Google Gemini、自定义（OpenAI 兼容）、自定义（Anthropic 兼容）

分三组，各自独立：
- **对话模型**：聊天、待办拆解、写报告用。
- **副对话 API**：主模型挂了自动顶上的备胎。
- **视觉模型**：屏幕锐评、干活监督、看图识歌用（要能看图的多模态模型）。若你的视觉模型本身也能好好聊天，勾上「视觉模型也有对话能力」可以少配一个。

### 零成本上手：用智谱的免费模型（推荐新手）
智谱的 **GLM-4.7-Flash（对话）** 和 **GLM-4V-Flash（视觉）** 都是**免费**的，对一只桌宠来说完全够用。全程不花钱，五步搞定：

1. 打开智谱开放平台 **<https://open.bigmodel.cn/>**，注册 / 登录。
2. 进后台创建一个 **API Key**。注意：账号初始自带的那个 key 只能在「体验中心」里用，**得自己在 API Key 页面手动新建一个**才能给外部程序（比如馒头）用。
3. 复制刚新建的这个 key。
4. 回到馒头 **设置 → API 配置**，服务商选**智谱 GLM**，填模型 ID：
   - **对话模型** 填 `glm-4.7-flash`
   - **视觉模型** 填 `glm-4v-flash`
   - 两处的 Key 都粘贴你刚复制的那个。
5. 分别点一下**「测试连通」**，出现绿色的勾 ✓ 就配置完毕了。

之后聊天、拆解待办、屏幕锐评这些功能就全亮了，且不产生费用。

### 施法特效
聊天时 AI 可以主动「施法」——比如它说着说着，屏幕四周真的会涌进一层寒潮冰晶。这类特效有冷却，一次对话最多来一次，图个惊喜。

## 5. 让它锐评你的屏幕

悬停 → 👁「让它锐评你的屏幕」。它会截下当前屏幕，结合你此刻在干嘛，开口点评几句（毒舌程度取决于你给的人设）。需要配好视觉模型。

这是一次性的主动点评，和下面的「干活监督」「屏摄日记」是三个独立功能，只是共用同一套看屏能力。

## 6. 待办 · 番茄钟 · 干活监督

悬停 → 📋 打开日程面板，最多三个 tab：**待办 / 研究 / 记录**（「研究」tab 只在开了自习室后出现，见第 7 节）。

### 加待办
在输入框敲任务回车即可。未完成的任务随时能：改名、改预估时长（5~90 分钟）、拖 ⠿ 手柄排序、删除。

### 两种开始方式
- **✦ AI 拆解**（需 API）：把一个大任务拆成几步，出一个确认页，你可以改名 / 改时长 / 删项 / 整组恢复原样 / 重新拆，确认后开跑。
- **直接开始**（永远可用）：配了视觉模型就带屏摄监督，没配就只是个计时器。

### 番茄钟
每个任务按预估时长倒计时，屏幕上有个悬浮小横条显示进度，可以**暂停 / 继续 / 完成 ✓ / 跳过 ⏭**。到点它会问你「还没好？」，5 秒不理自动续 15 分钟；每工作满 25 分钟提醒你歇一会儿。

**执行中还能随时调度**：
- **⏸ 暂停执行（进度保留）**：整组先收手，正在做的那条退回队列，进度不清零，回头点开始接着干。
- **▸ 执行这条**：想先做别的？在任何一条排队中的待办上点它，直接切换成当前执行项——原来那条自动退回队列，进度也保留。

**这些状态会存盘**：待办、进度、番茄钟的绝对时间，关机期间照常流逝，重开接着算——不会因为重启就「假装没这回事」。

### 干活监督
追踪任务期间，它会按你设的频率随机截屏，让视觉模型判断你在认真还是摸鱼：
- 认真 → 愉悦，夸你一句。
- 摸鱼 → 生气 + 一道冲击波特效；**连续 3 次摸鱼直接上冰封大招**。
- 没看清 → 无语，探问一句。

它每一次看屏都会记一笔流水账（监督、锐评、日记共用），在「记录」tab 里能回看（见第 8 节）。

## 7. 自习室：它跟你一起卷

设置 → 行为 → 打开「**自习室**」。开启后日程面板多出「**研究**」tab。

它不是陪读书童，是**同桌**：它有自己的宏大研究命题（比如「猫为什么会液化」），你开始执行待办它才开工——按你今天的待办条数拆出等量的「子课题」，你每勾完一条，它也"刚好"干完一条，冒个泡跟你汇报刚研究出的冷知识。你不干活，它也不干。

### 研究线
- 研究 tab 顶部是**研究线列表**：点当前目标名展开，可以切换、删除（双击确认）、或「＋」新开一条——命题可以自己写、让 **AI 起题**、或从预设池里**随机**抽。
- 每条研究线**独立**记进度、研究天数和成果档案，切来切去不丢进度。
- 研究成果都会存档（第几天学到的有标注），翻起来像一本它的学习笔记。
- 进度攒满 100% 正式**结题**，它会庆祝一下；结完题换条线或开个新命题继续。

### 联网检索（可选）
默认它纯凭大语言模型「研究」。想让冷知识有真实出处，去 设置 → API 配置 打开「**联网检索**」：智谱直连检索（约 0.01 元/次，复用对话 Key）、通义 / Kimi 走各自官方联网，都不用额外填；其他服务商可以填一个智谱检索 Key 兜底。

### 它也摸鱼：互相抓包
- 研究推进途中它会时不时开小差——逗猫、看鱼、泡茶等小剧场（角色包带了专属摸鱼动画就演包里的，偶尔还会打个盹）。**看到它摸鱼就点它一下**，算你抓到它一次；刚散场 5 秒内点到也算数。
- 反过来，屏幕监督抓到你摸鱼后的 30 分钟里，它也更容易跟着摸——风气是会传染的。
- 深夜睡觉时段它会正经睡觉、研究暂停，这不算摸鱼。

### 每日打卡图
研究 tab 底部「**生成今日打卡图**」：一张海报风格的方图——你和它的待办完成率 PK、互相抓包对决、专注分钟数、今天学到的冷知识，配一句它的判词（嘴硬程度视输赢而定）。可以保存成 PNG，发到群里立 flag 正合适。

## 8. 报告：日报 / 周报 / 日记

在 📋 的**记录 tab**里，从上到下：

- **观察流水**（折叠区，默认展开）：它每次看屏的原始记录——监督判定、锐评、日记共用这一本账，保留最近 100 条。
- **☀ 生成今日日报**：今天有观察记录且没在跑待办时出现，让它把今天的待办完成情况 + 观察流水写成一篇日报；**开了自习室的话，日报还会带上你俩的自习战况**。
- **✦ 周报**：按钮常驻，周五到周日可点（其余时间置灰并写明原因），待办按钮上还会有个小红点提醒你（本周看过一次就熄）。
- **历史日报 / 周报列表**（默认收起）：所有报告都能回看、删除（二次确认）。

另外，待办全部完成时会自动生成当日日报，或在待办 tab 点「结束今天，看报告」。

## 9. 听歌点头

设置 → 行为 → 打开「听歌点头」。

- **它怎么听**：优先抓系统声音（复用屏幕录制权限，无需额外装东西），抓不到才退回麦克风。
- **防误触**：只有检测到你电脑上真的有音乐播放器在跑（网易云 / QQ 音乐 / 酷狗 / 酷我 / Spotify / Apple Music / foobar 等）才会去分析，不会你看个视频它也乱点头。
- **怎么动**：踩上节拍就跟着上下点头，快歌折半拍、慢歌翻倍拍；纯抒情歌 8 秒锁不到拍就默认慢慢轻摇。点头时冒 ♪ 音符。
- **素材 BPM**：设置里可填点头动作的原生节奏（默认 89），让锁拍更准。
- **听歌点评**：跳舞时它会隔一阵子「问」一下现在放的是什么歌（通过播放器接口 / 窗口标题 / 网易云历史 / 看屏截图等多路子），认得出来就随口评一句。
- 设置面板里能看到实时音源、能量数值和节奏诊断。

## 10. 深夜睡觉

设置 → 行为 → 打开「深夜睡觉」，并设「睡觉时段」的起止小时（默认 23 点~7 点）。把起点和终点设成一样表示不睡；支持跨午夜，也支持同一天的午睡。

- **入睡**：到点后它会先打个哈欠，飘出一句催睡的话，然后慢慢闭眼进入睡觉循环，头顶冒 z。
- **醒来**：你点它一下会弄醒它；睡觉时段一结束它自己醒；放起激烈的音乐（节奏快、重低音）会把它吵醒陪你一起蹦；外部发来的消息或通知也会叫醒它。
- **音乐分级**：吵闹的歌响着它不犯困，舒缓的歌照睡不误。

## 11. 随机屏摄日记

设置 → 行为 → 打开「随机屏摄记日记」。

没有待办在跑的时候，它会时不时瞄一眼你的屏幕，客观记一笔 + 按人设开口点评一句。**它绝不会在日记模式里judge你摸鱼**——纯粹是个爱观察、话痨的桌面室友。睡觉、说话、或正在监督待办时它会自觉歇着。

记录都进 📋 的记录 tab。

## 12. 彩蛋合集

- **待机小动作**：闲着的时候每隔半分钟到一分半，随机来个哈欠、结霜飘雪、或随风轻摆。
- **连戳黑线**：8 秒戳 5 下 → 满头黑线 + 冰封 + 「……够了。」
- **犯困哈欠**：深夜到点先打个哈欠再催你睡。
- **整点起身提醒**：9~22 点的整点，它可能提醒你起来活动一下（可在设置里关）。
- **早安天气**：每天第一次开机（6 点后），它会按你所在城市报一句天气（可关）。
- **开机问候**：每次启动随机换一句问候语。

## 13. 换皮肤：角色包

馒头默认是程序画出来的小馒头，但你可以给它换上**任意角色的皮肤**（角色包 / persona）。

### 一个角色包是什么
一个文件夹，里面有角色的各种动画（待机、点击、情绪、睡觉、跳舞等的雪碧图）和一份说明文件。换上后，小馒头隐身，角色接管画面；**角色包里没做的动作不会强行触发**，角色始终保持自己的形象、停在待机，不会中途闪回小馒头（那样切来切去会很跳戏）。

包还可以带**自习室专属演出**（摸鱼 / 被抓包 / 思考动画）——带了就演角色自己的小剧场，没带就用通用演出，功能不受影响。

### 怎么导入/切换/删除
角色管理在**配置后台的「形象」tab**里（配置后台入口见下一节；形象 tab 默认隐藏，导入过一次包后会常驻）：

- **导入**：「＋ 导入形象包」→ 选那个文件夹（或 zip 包）。
- **启用 / 切回馒头**：卡片上的「启用这个形象」/「切回馒馒」。
- **删除**：卡片「删除」（二次确认；删的正好是当前皮肤会自动变回小馒头）。
- **动画清单**：看这个包都做了哪些动作，可以「后台大预览」单帧，或「▶ 桌宠」让真身现场演一遍；**彩蛋类动画可以逐条「禁用 / 启用」**，不想看哪个就关掉。
- **人设**：给这个角色写专属人设和名字（和设置面板同一份，两边同步，切包自动换用）。
- **尺寸**：调这个角色在桌面上显示多大（高度 120~1200 像素，默认 360），改完立刻生效。

### 动画门控
依赖特定动画的功能会跟着包走：包里没做 `sleep` 就开不了「深夜睡觉」、没做 `dance_nod` 就开不了「听歌点头」——设置里对应开关会置灰并注明缺哪个动作，切包后自动重新评估。小馒头本体动画齐全，不受影响。

> 角色包由配套的「雪碧图生产线」工具制作，本手册不展开制作流程。

## 14. 设置项全解

悬停 → ⚙ 打开设置，分四组：

### 基础
- **桌宠名字**：给它起名，会用在对话和台词里（按形象各存一套，切包自动换）。
- **人设文本**：它的身份和性格设定（同样按形象各存一套）。
- **暗色模式（黑曜馒头）**：本体和整个界面切换成黑玻璃质感，立即生效。

### 行为
- **专注时静音**：干活追踪时闭嘴不打扰。
- **整点起身提醒**：9~22 点整点提醒活动。
- **自习室**：它也有自己的研究待办，跟你一起自习。见第 7 节。
- **观察记录分享给 Agent**：把观察流水的文字摘要导出给本机的 AI Agent（不含截图），见第 16 节。不接 Agent 可以无视。
- **深夜睡觉** + **睡觉时段**：见第 10 节。
- **随机屏摄记日记**：见第 11 节。
- **每天首启报天气**：早安天气播报。
- **开机自动启动**：开机自动拉起桌宠。
- **听歌点头**：见第 9 节。
- **素材 BPM**：点头动作原生节奏。

### API 配置
- **禁用模型思考**：关掉支持的模型的「思考」过程，回复更快。
- **对话模型 / 副对话 API / 视觉模型**：见第 4 节。
- **视觉模型也有对话能力**：视觉模型够强时可省一个对话配置。
- **联网检索**：自习室研究查资料用（默认关），见第 7 节。

### 高级
- **屏摄频率**（快→慢 5 档，约 3 / 6 / 12 / 20 / 35 分钟浮动）：它多久看一眼屏幕。
- **摸鱼判定灵敏度**（宽→严 5 档）：监督时判摸鱼的严格程度。
- **聊天携带上下文条数**（1~500）：对话能记住多少条历史。
- **⌥ 开发者模式：配置后台**：进阶面板入口。
- **退出桌宠**。

另外：有新版本发布时，设置面板底部会出现「**⬆ 有新版本，去下载**」按钮（启动时和每天各检查一次，只提示、不自动安装）。

## 15. 配置后台（进阶）

设置 → 高级 → 「⌥ 开发者模式：配置后台」。这是一个独立窗口，给想深度调教的人用：

- **模型提示词 tab**：所有发给 AI 的指令模板都能改（回复规则、屏摄判定、锐评、日报周报、天气、听歌、自习研究……）。黄框表示你改过，清空即恢复默认。
- **桌宠台词 tab**：那些不经过 AI 的固定台词（问候、催睡、整点、开始、超时、完成、跳过、被戳烦、看屏兜底等），每项支持多行，随机取一句。
- **调试日志 tab**：每次 AI 请求和回复的原文、以及听歌拾音的自愈记录，排查问题用。
- **形象 tab**：角色包管理（见第 13 节）。默认隐藏，在配置后台右上角小圆点 1.5 秒内连点 5 下解锁，导入过包后就常驻了。

## 16. 让别的 Agent 控制它

馒头在本机开了一个 HTTP 接口，任何脚本、快捷指令、或 AI Agent 都能让它开口说话——比如让你的自动化助手在跑完一个任务时，通过馒头提醒你。

**接口**

```
POST http://127.0.0.1:8631/say
Content-Type: application/json

{ "text": "该喝水啦", "emo": "happy" }
```

- `text`：要说的话（必填）。
- `emo`：可选，情绪名（对应第 3 节：happy / surprise / angry / sad / speechless / gloomy / blackline），会让馒头说这句话时配上对应表情。
- 只监听本机 `127.0.0.1`，不对外网开放。发过去馒头会（必要时先醒过来）弹气泡说这句。

### 一键让别的 Agent 学会接入
把下面这段**原样复制**给你的 AI Agent（Claude、GPT、扣子、Dify 等都行），它就懂怎么驱动馒头了：

```
我的电脑上运行着一个叫「馒头」的桌宠，它在本机开了一个 HTTP 接口可以让它说话。
当你想通过桌宠提醒我某件事时，向这个接口发一个 POST 请求：

  POST http://127.0.0.1:8631/say
  Content-Type: application/json
  body: {"text": "要说的话", "emo": "情绪"}

字段说明：
- text：桌宠要说出来的话，必填，用自然口语，别太长。
- emo：可选，从下面挑一个和语气匹配的：
    happy(开心) / surprise(惊讶) / angry(生气) / sad(难过) /
    speechless(无语) / gloomy(低落) / blackline(无奈)
  省略则用平常表情。

示例：
  curl -X POST http://127.0.0.1:8631/say \
    -H "Content-Type: application/json" \
    -d '{"text":"该休息一下啦","emo":"happy"}'

请在合适的时机（任务完成、提醒事项、整点问候等）用这个接口让桌宠开口。
```

### 更深的双向对接
馒头还支持 Agent **派待办给它**、**读它的观察摘要**——走本机 `~/agent_pet` 目录下的文件协议：Agent 往里投递待办，馒头导入执行并回写状态；观察流水的文字摘要（不含截图）也会导出到这里，「设置 → 行为 → 观察记录分享给 Agent」可随时关掉。协议细节面向开发者，此处不展开。

## 17. 权限与常见问题

**为什么要屏幕录制权限？**
屏幕锐评、干活监督、屏摄日记、以及「抓系统声音听歌」都要截屏 / 抓声。**macOS** 下这些走屏幕录制权限，缺权限时它会直接帮你跳到系统「隐私与安全性 → 屏幕录制」设置页，勾上它、重开即可。**Windows** 下截屏和抓系统声音都不需要授权，开箱即用。

**不填 API Key 能用吗？**
能。拖动、眼神追随、戳一戳、表情、听歌点头、睡觉作息、彩蛋、番茄钟计时这些都不需要网络和 Key。只有「聊天、待办 AI 拆解、屏幕锐评 / 监督、写报告、识歌点评、自习研究」这些需要大模型的功能会灰着。

**它会挡我点东西吗？**
不会。除了它本体和浮现出来的面板，其余透明区域全部穿透，桌面照常用。

**改了设置没生效？**
绝大多数设置（含暗色模式、尺寸、人设）都是即时生效的。个别情况重开一下桌宠即可。

**它偷偷把我的屏幕 / 对话传到哪了吗？**
截屏和对话只发给**你自己配置的那个大模型 API**，馒头本身不设服务器、不上传到任何第三方。想完全离线，就别填 Key，纯本地陪伴功能照常。
