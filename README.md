# 馒头 Bunbun 🤍

> 一只住在你桌面角落的毛玻璃小馒头。零素材、纯代码画出来，会看着你的鼠标、跟你聊天、盯你干活、陪你自习、听你放的歌点头、到深夜自己去睡觉。
>
> **也可以换成你喜欢的任何角色** —— 不用会画画、不用会代码、不用花钱：一张立绘 + 免费的 AI 视频额度，剩下的交给内置的「动画工坊」。

桌面宠物，支持 macOS 与 Windows。本体不占资源、不挡鼠标、不上传数据；带 AI 的功能只连你自己配置的大模型，可以用**免费模型**跑起来。

## ✨ 能做什么

- **🫧 陪伴本体**：程序化毛玻璃馒头，眼珠追鼠标、随机眨眼、可拖动、多屏跳岛、暗色「黑曜」皮肤。
- **💬 聊天**：流式打字机气泡，按语气自动切表情，还能主动「施法」放特效。支持 12 家大模型服务商。
- **😀 7 种情绪**：愉悦 / 惊讶 / 生气 / 难过 / 无语 / 低气压 / 黑线，各带眼型、粒子和音效。
- **👁 屏幕锐评**：截屏点评你正在干嘛（毒舌程度看人设）。
- **📋 待办 · 番茄钟 · 监督**：AI 拆解任务、番茄钟计时、暂停 / 任选一条执行、随机截屏抓你摸鱼（连续摸鱼上冰封大招），跨重启持久化。
- **📚 自习室**：它有自己的研究命题，跟你同桌自习——你追踪待办它就同步推进「子课题」、汇报冷知识（可选联网检索）；它也会摸鱼等你抓包，一天结束生成 PK 打卡海报图。
- **📊 报告**：日报 / 周报 / 凭观察写的日记型日报，日报还会带上自习战况。
- **🎵 听歌点头**：抓系统声音实时对拍点头，还能报出你在听什么歌。
- **😴 深夜睡觉**：到点打哈欠去睡，吵歌会把它闹醒陪跳。
- **📷 屏摄日记**：闲时瞄一眼屏幕记一笔 + 点评（纯陪伴，不判摸鱼）。
- **🎭 换皮肤**：导入角色包（persona），给它换一整张脸；包里没做的动作就不触发，角色始终保持自己的样子，不会中途闪回小馒头。
- **🎨 自己做形象**：内置**动画工坊** —— 传一段绿幕视频，浏览器里当场拆帧、抠图、对齐循环、打包成雪碧图。不装任何软件、不写一行代码，用免费 AI 视频模型就能把喜欢的角色搬上桌面。
- **📥 贴边收起**：拖到屏幕右边缘就滑出去，留个小把手，点一下再回来（多屏时右边还有屏幕则照旧跳屏）。

完整功能与使用说明见 **[用户手册](docs/用户手册.md)**。

## 📦 安装（普通用户）

去 [Releases](https://github.com/Bunnnnn-722/mantou-deskpet/releases) 下载对应系统的包：

### macOS
- 下载 `mantou-pet-<版本>-mac-*.dmg`，打开把馒头拖进「应用程序」。
- 安装包未做苹果签名，首次打开若提示「无法验证开发者」，**右键点图标 → 打开 → 再点打开**即可（只需一次）。

### Windows
两种包任选其一：
- **安装版**（`mantou-pet-<版本>-win-*.exe`）：像装普通软件一样，双击按向导走完，会进开始菜单、能创建桌面快捷方式、能从「控制面板」卸载。适合长期用。
- **免安装版 / 绿色版**（`...portable.exe`）：不安装、不写系统、不留痕迹，双击 exe 就直接跑，可以丢 U 盘里带走。不想让它动你系统就用这个。
- 首次运行若被 Windows SmartScreen 拦一下，点「更多信息 → 仍要运行」即可。

启动后馒头会从桌面浮现。把鼠标移上去露出菜单，拖动它换位置，点齿轮进设置。

> **平台差异**：桌宠本体、聊天、待办、听歌点头等在两个系统上一致。Windows 上「听歌点头」抓系统声音**不需要任何权限**（WASAPI 回环），比 macOS 还省事；macOS 首次用截屏 / 听歌需在系统设置里给一次屏幕录制权限。

## 🤖 配 AI（可选，但推荐）

聊天 / 待办拆解 / 屏幕锐评这些「聪明」功能要一个大模型 API。**推荐用智谱的免费模型零成本上手**：

1. 去 <https://open.bigmodel.cn/> 注册，在后台**自己新建一个 API Key**（初始那个只能在体验中心用）。
2. 馒头 **设置 → API 配置**，服务商选**智谱 GLM**：对话模型填 `glm-4.7-flash`、视觉模型填 `glm-4v-flash`，两处粘贴你的 Key。
3. 分别点「测试连通」，出现绿勾 ✓ 即可。免费额度对桌宠完全够用。

不填 Key 也能用拖动、表情、听歌点头、睡觉、番茄钟计时等纯本地功能。

## 🎨 把喜欢的角色变成桌宠

馒头自带的形象是纯代码画的小馒头，但它的形象层是**可替换**的 —— 而且做一套形象，**不需要美术功底、不需要建模、不需要花钱**。

整条路只有四步：

| | 做什么 | 用什么 |
| --- | --- | --- |
| 1 | 把角色图的背景换成**纯绿色**，得到一张「绿底立绘」 | 任意 AI 绘图工具的图生图 |
| 2 | 拿这张立绘当首帧参考图，**生成几段 4 秒动画**（待机、摸头、点头…） | 免费的 AI 视频模型，每天都有额度 |
| 3 | 把视频丢进**动画工坊**，自动拆帧 → 抠图 → 对齐循环 → 打包 | 桌宠内置，十几秒一条 |
| 4 | 点「启用这个形象」 | 它就站在你桌面上了 |

动画工坊做了不少脏活，省得你自己折腾：

- **自动抠图**：绿幕 / 蓝幕 / 品红幕自动识别，半透明边缘做去污和去溢色，不会留一圈绿边；
- **自动对齐循环**：免费模型生成的视频首尾常常对不上，工坊会在后段找与首帧最接近的一帧提前收尾，实在接不上就自动**倒放补循环**，保证不跳变；
- **自动对齐大小**：不同批次生成的视频人物一大一小很常见，按人物外框自动贴齐待机姿势；
- **槽位随便换绑**：哪条动画放哪个位置用下拉框改，不用重命名文件；摸鱼想做十条就做十条；
- **首尾帧体检**：循环动画首尾必须一致、开机浮现 / 入睡 / 贴边这些过渡动画首尾必须不同 —— 不合规当场黄字提醒；
- **点击区域可视化**：在待机帧上直接框选头 / 身体 / 手，点哪儿播哪条动画。

没做的动作不会强行触发，对应的功能开关会自动置灰 —— 只传一条待机动画也能先玩起来，剩下的慢慢补。

**[全套动画提示词模板](docs/角色包动画提示词模板.md)** 也放进仓库了 —— 24 个槽位每条都拼好了，复制就能用。不过那是照着我自己的角色调的，动作和神态带着她的性格，你的角色多半要改一改（模板开头写了哪些该留、哪些该换）。

详细步骤见 **[用户手册 · 第 13 节](docs/用户手册.md#13-换皮肤角色包--自己做一个形象)**；桌宠里也内置了一份图文说明（配置后台 →「形象」→「角色包制作说明」）。

## 🔒 隐私

- 截屏和对话**只发给你自己配置的那个大模型 API**，本项目不设服务器、不上传任何第三方。
- 想完全离线：不填 Key，纯本地陪伴功能照常。
- 屏幕锐评 / 监督 / 屏摄日记 / 抓系统声音听歌：**macOS** 走屏幕录制权限，缺权限时会引导你去系统设置开启；**Windows** 截屏与音频回环都不需要授权。
- 本地配置（含 API Key）存在 `config.json`，已在 `.gitignore` 中，不会入库。

## 🛠 技术

- **Electron**（无边框透明置顶窗口 + 鼠标穿透）
- 桌宠本体：**纯 SVG + CSS**，零图片素材，程序化逐帧渲染
- 角色包：雪碧图（sprite sheet）+ manifest 帧网格，运行时逐帧绘制
- 大模型：OpenAI / Anthropic 双协议兼容，内置 12 家服务商预设
