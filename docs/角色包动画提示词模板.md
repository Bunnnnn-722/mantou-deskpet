# 馒头桌宠 · 角色包动画提示词模板

> 配套「动画工坊」使用 · 适用于豆包等支持参考图的视频生成工具

## 先说一句

这套提示词是照着我自己的角色调出来的，大家可以直接参考着用 —— 如果哪句描述跟你的角色不太贴合，手动改成它会做的动作就好。

有一点建议留意：那些结构性的约束尽量别删 —— `不要变焦`、`人物保持原位`、`嘴巴保持闭合`、`背景保持纯绿色`、`人物的大小、比例和色调保持不变`、`循环动画`。这些是给模型上的镣铐，删掉容易翻车（人物走位、变焦、张嘴说话、背景渐变，抠图就全废了）。

`◆` 是特色元素占位符，换成你角色的东西就行（雪花 / 花瓣 / 火星 / 小鱼 / 星尘 / 电流……）。

---

## 一、怎么用这份模板

- 每条提示词都已拼装完整，整段复制进视频生成工具即可。◆ 符号请替换成你角色的特色元素（如雪花/花瓣/火星/小鱼），括号里给了示例，用的时候把括号一起删掉。
- 所有视频都用同一张「纯色底立绘」当首帧参考图（睡眠链用闭眼立绘，见第二章），这样切换动画时角色不会跳变。工具支持尾帧参考图的话，把尾帧也设成同一张，循环最顺滑；不支持也没关系，工坊会自动对齐循环。
- 模板默认绿色背景。角色本身带绿色（绿发/绿衣）时，把提示词里所有「纯绿色」替换成「纯蓝色」或「纯品红色（洋红色）」，整套统一用一种。
- 时长 3～6 秒即可。生成完在桌宠「配置后台 → 形象 → 动画工坊」按槽位上传，自动抠图入包。
- 豆包实操要点：视频生成一律从输入框的「视频生成」入口进（重新生成也回这个入口再来一次，别直接点它的回复让它重生成，容易出 bug）；豆包没有首尾帧设置，循环动画要在提示词末尾手动补一句「首尾帧保持一致，人物最后回到最初始的状态」。
- 免费额度：豆包/即梦/小云雀都能薅到 Seedance 资源，豆包每天有免费额度——慢慢用，就能把喜欢的角色全套产出来。
- Fast 这类快速模型可能出现人物细节偏移（实测：瞳色变了）。生成完盯着角色细节看一眼，不对就在同一页面重试，抽到符合预期为止——反正免费。
- 不用全做！只传待机（idle）就能启用形象；推荐入门三件套：待机 + 摸头 + 听歌点头，其余想到再补。

## 二、准备工作：立绘转纯色底（图生图）

把你的角色图变成「纯绿底标准立绘」：用任意 AI 绘图工具的图生图/图片编辑功能，上传两张图——图1是角色图，图2是一张纯绿色参考图（画图软件填充纯绿保存即可），配这条提示词：

```
图1是角色图，图2是目标背景颜色的参考图。只保留图1中的主体人物一个，去掉人物脚下的投影和阴影，去掉背景中的其他人物、物件、文字和界面元素，把背景替换成与图2颜色完全一致的纯绿色纯色背景，背景是完全均匀的纯色，没有任何纹理、渐变、噪点和图案，人物本身的姿势、颜色、细节保持完全不变，人物完整全身可见。请给人物的边缘添加一圈细描边，注意要非常细，不超过2px。
```

睡眠链还需要一张「闭眼立绘」：拿上一步的成品立绘再跑一次图生图：

```
将人物的眼睛改成闭眼，其余的姿势、颜色、细节、表情、背景保持完全不变
```

贴边动画还需要一张「纯绿空白帧」：跟立绘同尺寸的纯绿色图片，画面里什么都没有（画图软件填充纯绿保存即可，第一步用的那张纯绿参考图就能直接拿来当空白帧）。
